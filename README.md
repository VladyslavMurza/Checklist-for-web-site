# Checklista strony internetowej

Krótka checklista i baza wiedzy o tym, jak zaprojektować stronę internetową, która jest czytelna, działa na każdym urządzeniu, jest dostępna (WCAG) i przynosi klientów.

| 📚 | **[docs/](docs/00_SPIS_TRESCI.md)** — pełne opracowanie 14 tematów | nauka i szczegóły |
| 🔗 | **[zrodla/](zrodla/15_mapowanie_zrodel.md)** — mapowanie źródeł: skąd pochodzi każda informacja | weryfikacja |

## Tematy

Struktura strony · UX · Responsywność (RWD) · Dostępność (WCAG 2.0–2.2) · Design wizualny · Wydajność (Core Web Vitals) · SEO · RODO i cookies · Testowanie · Marketing i konwersja · CTA · Analityka

## Jak korzystać

1. Przejdź przez [CHECKLIST.md](CHECKLIST.md) przy projektowaniu w Figmie i ponownie przed publikacją strony.
2. Przy każdym punkcie jest link do pliku z wyjaśnieniem i przykładami.
3. Aby odhaczać punkty na GitHubie, skopiuj checklistę do nowego **Issue**.
