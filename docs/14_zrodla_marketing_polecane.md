# 14. Źródła polecane przez web designerów i marketerów

Do plików 11–13 użyto przede wszystkim źródeł, które w branży uchodzą za wiarygodne.
Warto je czytać też samodzielnie.

## UX i projektowanie
| Źródło | Dlaczego warto mu ufać |
|---|---|
| **Nielsen Norman Group (nngroup.com)** | Firma Jakoba Nielsena i Dona Normana; badania użyteczności od 1998 r., standard w UX |
| **Baymard Institute (baymard.com)** | Ponad 200 000 godzin badań UX e-commerce; wiodące źródło o koszyku i checkoutcie |
| **Smashing Magazine (smashingmagazine.com)** | Jeden z najbardziej znanych magazynów dla web designerów i front-endowców |
| **web.dev / Google Search Central** | Oficjalne wytyczne Google: Core Web Vitals, SEO |
| **W3C WAI (w3.org/WAI)** | Twórcy standardu WCAG |
| **Laws of UX (lawsofux.com)** | Zasady psychologii w projektowaniu (prawo Hicka, Fittsa, Jakoba) |

## Marketing i konwersja
| Źródło | Dlaczego warto mu ufać |
|---|---|
| **CXL (cxl.com)** | Szkoła i blog o CRO i analityce; artykuły oparte na badaniach i testach |
| **Unbounce (unbounce.com)** | Platforma landing page; raporty z milionów konwersji |
| **HubSpot Blog (blog.hubspot.com)** | Twórcy pojęcia inbound marketing; praktyczne poradniki |
| **Semrush / Ahrefs (blog)** | Narzędzia SEO; poradniki o SEO i lejkach opartych na danych |
| **Google Analytics Help** | Oficjalna dokumentacja GA4 i UTM |
| **Think with Google** | Badania zachowań konsumentów od Google |
